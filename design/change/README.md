# 機能追加・改修ドキュメントテンプレート

## ファイル構成

- `01_変更要求書_template.md`
  - なぜ変更するのか、誰が何に困っているか、何を達成したいかを整理する。
- `02_変更要件定義書_template.md`
  - 承認された要望を、実装・テスト可能な要件へ変換する。
- `03_影響調査書_template.md`
  - 既存画面、API、DB、バッチ、外部連携、運用などへの影響を調査する。
- `04_変更仕様書_template.md`
  - 小規模から中規模の改修を1ファイルで管理する。

## 推奨する使い分け

### 小規模改修

`04_変更仕様書_template.md` を使用する。

例：

- 文言変更
- 入力チェック追加
- 一覧項目追加
- 軽微な検索条件追加

### 中規模改修

次の3ファイルを使用する。

1. `01_変更要求書_template.md`
2. `02_変更要件定義書_template.md`
3. `03_影響調査書_template.md`

例：

- APIとDBの変更
- 権限追加
- 複数画面への影響
- データ移行

### 大規模改修

中規模改修の3ファイルに加え、個別の移行計画書、リリース計画書、
ロールバック計画書、テスト計画書を作成する。

例：

- 認証基盤変更
- 決済方式変更
- 複数サービス横断
- 大量データ移行
